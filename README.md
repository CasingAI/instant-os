
# Instant OS

**Instant OS 里，你消费的一切内容，都由 AI 生成。**

**本仓库的每一行代码，同样全部由 AI 编写——没有任何一行是人类手写的。**

这不是在传统操作系统上「加一层 AI 功能」，而是反过来：桌面、窗口、Dock 只是壳，**应用、网页、邮件——你在系统里看到、安装、阅读、交互的一切，都是 AI 按需即时生成的**。没有预置应用目录，没有真实网络请求，没有静态内容库。你输入一个意图，AI 产出内容；你换一个 URL、搜一个关键词、写一封邮件，AI 再次生成。

Instant OS 是一个在浏览器中运行的 AI 原生桌面环境。它复刻熟悉的桌面交互——菜单栏、图标、Dock、可拖拽窗口——但底层逻辑是：**内容不存在于安装包或服务器里，只存在于每一次生成之中。**

## 核心理念

| 传统系统 | Instant OS |
|----------|------------|
| 应用集市上架固定应用 | 集市列表、搜索结果、应用本体，全部由 AI 现场生成 |
| 浏览器加载远程 HTML | 任意 URL 对应的高保真页面，由 AI 即时渲染 |
| 邮件来自真实 SMTP 服务器 | 收件箱、往来回复、新联系人，由 AI 扮演并生成 |
| 帮助是静态文档或外链 FAQ | **帮助用 AI 对照当前系统真实能力，直接告诉你功能在哪、怎么用** |
| 系统时间只影响时钟显示 | **改系统时间会改写大量生成内容的时代语境（古代 / 当下 / 未来）** |
| 内容预先存在，用户来消费 | **内容在用户操作时诞生，消费即生成** |

一句话：**Instant OS 是一个「生成式操作系统」——你使用的不是软件，是 AI 持续产出的内容流。**

## AI 生成什么

### 应用集市 — 从列表到应用，全程生成

- **发现页与搜索**：没有固定目录。策展 AI 根据提示现场构思微应用概念；搜索 AI 根据关键词想象匹配结果。每一批列表都是新的。
- **安装**：点击安装后，生成器 AI 流式输出完整可交互的单页应用（HTML 或 Three.js 3D），写入本地并出现在桌面。带 **AI 运行时** 能力标签的微应用可在 iframe 内调用系统 AI（流式对话），用量计入「AI 用量」统计。
- **评价驱动更新**：已安装的应用可在详情页写评论、打分。发布评价后，主按钮会从「打开」变为「更新」，应用集市图标也会出现待更新角标——这是系统在提醒你：有新反馈待 AI 消化。点击「更新」，生成器 AI 会读取你的评论，在现有源码基础上流式生成新版本；应用会随你的意见而「进化」。
- **卸载**：桌面或 Dock 图标右键可选择卸载，确认后从本地移除应用及其数据。

你安装的每一个 App，都是 AI 写出的代码，不是开发者提交的包。

### 网络浏览器 — 没有真实网页，只有 AI 渲染的页面

- 输入任意 URL，浏览器**不发起网络请求**，而是由 AI 根据域名与路径，高保真还原该站点的静态快照。
- 点击链接、提交表单，系统接管导航，AI 为下一个 URL **重新生成**页面。
- 书签、历史、缓存记录的是你「生成过」的页面，而非下载过的资源。已生成的页面缓存保存在**数据空间**（IndexedDB），可在系统设置中按应用管理。

你在网络浏览器里「浏览」的，是 AI 对互联网的即时想象，不是互联网本身。

### 邮件 — 整个收件箱都是 AI 虚构的世界

- 首次打开，AI 生成一批虚拟收件箱邮件，营造日常中文邮件环境。
- 回复时，AI 代入发件人身份撰写回信；给新地址写信，AI 即时构思联系人并回复。
- 没有真实邮箱服务器，没有外部投递——**每一封你读到的、写出去后收到的，都是 AI 生成的文本。**

### 内置 AI 应用 — 系统自带的生成式体验

除应用集市安装的微应用外，Instant OS 还预置了一批由 AI 驱动的内置应用，均将虚构内容本地持久化，仅供娱乐与演示：

| 应用 | AI 生成什么 |
|------|-------------|
| **新闻** | 可调整日期的中文新闻版面；支持查看「未来新闻」，邻近日标题保持叙事连贯；版面时代语汇会跟随所选日期（古代 / 当代 / 未来） |
| **图书** | 仿 iBooks 拟物风格的书架、书城与阅读器；AI 虚构网文，涵盖系统、末日囤货、都市、玄幻等分类；加入书架后流式撰写，可边生成边看进度 |
| **月历** | 拟物风月视图；节气与节假日语境随系统时间变化；可 AI 生成月度标注，并与新闻等日期入口联动 |
| **天气** | 虚构的逐小时与未来几天预报；可搜索任意城市即时编造天气 |
| **股票** | 虚构的股市看板与个股详情；可搜索股票代码或公司名；支持将默认股票或市场看板固定为通知中心小组件显示，并与通知中心双向同步 |
| **翻译** | 中文译为内置「宇宙语言」（哈啾噜噜语、波叽哇啦语、哈基语等） |
| **CatGPT** | 与猫咪之神的喵喵对话，记录保存在本地 |
| **五子棋** | 15×15 经典五子棋；支持人人对战、人机对战与**双 AI 对战**（本地启发式 AI 对当前模型 AI）。人机与双 AI 模式下由 AI 分析局面后落子；含开局抽签、思考状态、胜负特效与音效；窄屏下以底部面板展示对局信息与操作 |
| **帮助** | **系统级 AI 使用指南**：用自然语言直接问当前系统有哪些功能、在哪里、怎么用；助手对照本机真实实现作答，并用界面文案指路 |
| **钥匙串** | 集中管理多供应商 AI 账户与凭证（配合系统设置中的账户页） |
| **任务管理器** | 监视已打开程序与窗口；性能页观察 AI 输出速度 |
| **事件日志** | 复盘各应用的 AI 调用会话与耗时 |
| **系统信息** | 查看设备与浏览器环境诊断信息 |

### 3D 实验室 — Three.js 场景与物理引擎

- 输入场景描述，AI 流式生成基于 **Three.js** 的 3D 页面，使用内置 CC0 模型素材目录。
- 可选开启 **Rapier** 物理模拟，并加载物理 Demo 示例。
- 独立于应用集市的微应用生成流程，便于验证素材目录与运行时注入。

应用集市在检测到 3D 相关意图时，也会生成 Three.js 微应用（含可选物理效果），与 3D 实验室共用同一套运行时与素材体系。

### 通知中心 — 小组件与系统通知

- 菜单栏右侧可打开通知中心，查看由 AI 生成的**天气**与**股票**小组件快照。
- 小组件可一键跳转到对应内置应用；内容同样为虚构数据，不代表真实行情或气象。
- **股票**小组件与股票应用共享数据源：首次生成会写入默认自选股；在股票应用中可将某只自选或市场看板「固定为通知中心显示」，小组件会随之更新。
- 系统级通知也会汇入此处：图书生成进度、微应用安装状态、存储空间告警、生成应用进程隔离降级等；可在系统设置中调整相关偏好。

### 图书 — AI 虚构网文书架

- 仿经典 iBooks 拟物风格，提供**书架**、**书城**与**阅读器**完整流程。
- 书城按系统、末日囤货、都市、玄幻、离谱指南等分类展示 AI 虚构书目；加入书架后 AI **流式撰写章节**，生成过程可在应用内与通知中心跟随阶段与进度。
- 书籍索引保存在系统空间，章节正文保存在数据空间（IndexedDB），可在系统设置中管理。

### 帮助 — 用 AI 读懂当前这套系统

帮助不是一份写死的说明书，而是 **Instant OS 自带的 AI 使用指南**：

- 用自然语言直接问：有哪些功能、某个能力在哪、该点什么、按什么顺序操作。
- 助手会对照**当前安装的这版系统**作答：后台可检索打包的源码快照、只读查看本地存储键与用量，确认真实能力后再回答。
- 对普通用户，回答用菜单名、窗口名、按钮文案与桌面 / 程序坞位置指路，而不是堆文件路径或实现细节。
- 系统功能演进后，帮助仍能跟着「当前代码」解释用法——这是静态 FAQ 做不到的。

### 系统时间 — 改时间，等于改整机内容的时代

Instant OS 的「现在」可以由你设定，而不只是墙上的真机时钟：

- **系统设置 → 日期与时间**：跟随设备真实时间，或手动设定任意时刻（含公元 / 公元前）。开机向导也可完成首次设定。
- 改时间会改变大量「以今天为锚」的体验：菜单栏时钟、月历节气与节假日、新闻版面的时代语汇与事件、邮件时间线，以及其它按系统时钟生成或展示的内容。
- 因此可以把系统拉到**古代**读古风语境的新闻与月历，推到**未来**查看尚未到来的版面，或在任意历史节点之间切换——时间是内容生成的语境旋钮，而不只是显示用的数字。
- **月历**提供拟物风月视图，随系统时间呈现对应节气 / 节假日；可请 AI 生成当月标注，并跳转到对应新闻日刊等关联入口。多处日期选择共用同一套日期时间面板。

### 运维与诊断

- **任务管理器**：列出已打开应用与窗口状态，可切换前台或结束应用；性能页按采样间隔记录 AI 输出速度曲线。
- **事件日志**：汇总各调用点的 AI 请求会话，便于排查与复盘；占用可在设置中管理。
- **系统信息**：汇总操作系统、浏览器、处理器、内存、显示器、网络与存储配额等诊断信息。
- **钥匙串**：与账户设置配合，管理多供应商凭证与条目。

### iCode — 微应用开发环境

iCode 是 Instant OS 内置的微应用 IDE，默认出现在桌面与程序坞。应用集市负责安装别人的创意，**iCode 负责在系统内创造并发布你自己的微应用**。

- **项目与导入**：新建内部项目（桌面自动创建占位入口）、从已安装微应用导入独立副本、导入 / 导出 ZIP 程序包以备份或分享。
- **对话式开发**：左侧实时预览，右侧多面板调试——**对话**（AI 流式生成或局部修改源码，支持 **Markdown** 渲染、**上下文 token** 与**历史记录**，生成中可**取消**）、**源码**（Monaco 编辑器，改完一键运行刷新预览）、**配置**（名称、描述、图标、主题色与能力标签）、**数据**（查看与编辑微应用本地存储）、**控制台**（预览 iframe 日志与报错）。
- **能力授权**：预览中的微应用若需 **3D** 或 **AI 运行时** 能力而项目尚未开启，AI 可在对话中发起授权请求，确认后立即生效，无需手动切到配置页。
- **发布流程**：iCode 内编辑仅在沙箱预览；确认后「发布到桌面」才更新外部应用。支持保存草稿，有未发布改动时关闭会提示，也可选择发布后再关。
- **项目管理**：删除 iCode 项目时可选择**同时卸载**对应桌面微应用；支持普通 HTML 与 Three.js 3D 微应用；可从菜单栏隐藏 iCode 图标（不影响已打开窗口）。

### 桌面与程序坞 — 类 iOS / macOS 的启动器

桌面与 Dock 是固定的系统壳，负责承载与调度 AI 生成的内容，但交互已接近真实操作系统：

- **多页桌面**：图标按网格自动分页，左右滑动或点击页码圆点切换；图标过多时自动扩展新页。
- **图标排序**：长按拖动桌面图标可跨页重新排列，顺序持久保存；拖动时其余图标会摆动让位。
- **桌面文件夹**：将一个图标拖到另一个上即可合并为文件夹；点开后在独立浮层中管理内容，支持命名与持久化；文件夹图标以九宫格缩略预览内部应用，并可与程序坞拖放协作。
- **程序坞固定**：右键图标可选择「保留在程序坞中」或「从程序坞中移除」。固定区与当前运行但未固定的应用之间以分隔线区分，布局同样本地持久化。精细指针设备上悬停 Dock 图标可显示应用名称。
- **程序坞大小**：系统设置 → 程序坞 可调图标尺寸档位，窄屏下 Dock 自动适配视口宽度。
- **窗口**：拖动窗口时可短暂窥视下层桌面（桌面揭示）；贴边窗口可在工作区内拖拽边缘调整大小；最小化动画对准对应 Dock 图标；应用内确认与提示优先使用**窗口级模态框**，避免遮挡其他窗口内容。
- **进程隔离**：已安装的非系统微应用默认在更严沙箱中运行，并通过心跳监测异常；不支持时会降级并在通知中心提示。开发者选项中可临时切回旧加载方式以便排查。
- **存储预警**：系统或数据存储可用空间不足 20% / 10% 时，顶部会弹出警告横幅，并同步到通知中心；点击可直达系统设置的「存储空间」页查看与清理。
- **冷启动**：首次打开或冷启动时展示启动闪屏，与设置助手进场过渡对齐，再进入桌面。

窗口管理、菜单栏、通知中心、设置界面与其余壳层不产出内容，只呈现 AI 生成的内容。这也是 Instant OS 与「AI 助手插件」的本质区别：AI 不是附加功能，而是内容来源本身。

### 显示、壁纸与表情符号

- **系统设置 → 壁纸** 可在多款内置渐变、纯色与图案壁纸间切换，选择后立即生效；浅色壁纸下桌面图标标签自动适配对比色。
- **系统设置 → 显示 → 表情符号** 可选择 Apple Color Emoji 的加载策略（自动 / 开启 / 关闭）。Emoji 字体加载不再阻塞系统启动（慢网络下最多等待 3 秒）。
- 非 Apple 平台下，表情符号在图标与文字混排中可能出现垂直偏移；系统提供**垂直偏移校正**——启动时可自动测量并写入偏移量，也可在设置中手动微调（按字号比例的 em 单位应用）。

### AI 用量与账户

- **系统设置 → AI 用量** 汇总各应用与行为的 Token 消耗，可按日、按应用、按行为类型查看明细，支持清除历史记录。
- **系统设置 → 账户** 支持多供应商配置：添加 / 切换供应商与模型、选择默认账户、按供应商开启 Thinking 等。
- **钥匙串** 应用提供更完整的凭证与供应商条目管理界面。
- **系统设置 → 外链 AI 授权** 可查看并撤销经 Bridge 授权的外部应用（外链平台仍为实验性、未完成特性）。

### 开发者选项中的实验特性

部分能力默认关闭或仅供调试，产品与协议尚未定稿：

- **全屏沉浸顶栏**：全屏时隐藏菜单栏与标题栏，指针移近屏幕顶部再唤出。
- **语音识别**：Web Speech API 演示应用；开启后才会出现在桌面与程序坞。
- **外链应用调试**：将本地外链应用开发服务器临时挂到桌面，在 Instant OS 内走宿主真实 AI；会话级，重启后消失。
- **停用窗口合成器加速**：临时关闭生成应用的进程隔离加载方式，便于排查兼容问题。

### 启动崩溃守护 — 启动失败时的诊断界面

- 主应用模块加载之前，会注入一层极轻量的**启动守护**：监听全局脚本错误与未处理的 Promise 拒绝，并拦截控制台输出，为后续诊断留存上下文。
- 若启动阶段发生不可恢复错误（挂载节点缺失、字体初始化失败、组件树渲染异常等），系统会进入全屏**诊断界面**，展示主要错误、错误事件列表、近期控制台输出与运行环境信息。
- 诊断界面提供**重新加载**与**复制诊断信息**操作，便于本地复现或向他人反馈问题。
- 应用根组件外包裹错误边界，将 React 组件树内的未捕获异常同样汇入上述诊断流程。

| 更换桌面壁纸 | 即时切换内置壁纸与图标标签配色 |

## 快速开始

Instant OS 完全依赖 AI 生成内容，**必须先配置 API Key 才能使用**。

### 环境要求

- Node.js 18+
- [pnpm](https://pnpm.io/)（推荐）或 npm

### 安装与运行

```bash
pnpm install
pnpm dev
```

开发服务器：**http://localhost:6173**

```bash
pnpm build
pnpm preview   # 默认 http://localhost:6174
```

### 配置 AI 账户

首次启动会进入设置助手；也可在 **系统设置 → 账户** 中修改。

**界面配置（推荐）**：在账户或钥匙串中添加供应商、填写 API Key、选择模型（下拉列表显示友好名称，如「GPT-5.4 Mini」）；可设置默认账户，部分供应商支持开启 **Thinking 模式**（延长推理时间以提升生成质量）。配置保存至浏览器本地，五子棋人机与双 AI 对战模式会显示当前对手所用模型。

**环境变量**：在项目根目录创建 `.env.local`：

| 变量 | 说明 |
|------|------|
| `VITE_OPENAI_API_KEY` | API Key |
| `VITE_OPENAI_BASE_URL` | 可选，自定义 API 基址 |
| `VITE_OPENAI_MODEL` | 可选，默认 `deepseek-v4-flash` |

### 支持的 AI 供应商

| 供应商 | 默认 Base URL | 预设模型示例 |
|--------|---------------|--------------|
| DeepSeek | `https://api.deepseek.com/v1` | DeepSeek V4 Flash、DeepSeek V4 Pro |
| OpenAI | `https://api.openai.com/v1` | GPT-5.4 Mini、GPT-4o 等 |
| 小米 MiMo | `https://api.xiaomimimo.com/v1` | MiMo V2.5 Pro、MiMo V2.5 Pro UltraSpeed、MiMo V2 Flash 等 |

## 数据与隐私

- **API Key** 仅存于浏览器本地，仅用于向所选 AI 供应商发起生成请求。
- **生成产物**（微应用、网络浏览器页面、邮件、新闻、天气、图书章节等）及**启动器布局**（桌面图标顺序、程序坞固定项、壁纸偏好）缓存于本地，无后端同步。大体量内容（网络浏览器页面缓存、图书正文等）存放在独立的 **IndexedDB 数据空间**，与系统设置（localStorage）分开计量，可在「存储空间」中按应用查看与清理。
- **除 AI API 调用外**，系统不依赖外部 CDN 或远程内容服务——因为内容本就不从外部来，而是从模型来。

## 开发说明

### 常用脚本

| 脚本 | 说明 |
|------|------|
| `pnpm dev` | 开发服务器（端口 **6173**） |
| `pnpm build` | 类型检查 + 生产构建 |
| `pnpm preview` | 预览构建产物（端口 **6174**） |
| `pnpm vendor:three` | 将 Three.js 复制到 `public/vendor/` |
| `pnpm vendor:rapier` | 将 Rapier 复制到 `public/vendor/` |
| `pnpm vendor:runtime` | 同时执行上述两项 |
| `pnpm assets:3d` | 下载 CC0 3D 素材包 |
| `pnpm catalog:3d` | 根据素材生成模型目录 |

- 构建时执行 `tsc -b` 类型检查（见 `vite.config.ts`）
- 3D 相关提示词示例可参考根目录 `3d-app-prompt-example.md`（由 `scripts/dump-3d-app-prompt-example.mjs` 生成）

### 启动崩溃测试

在开发或排查启动问题时，可在地址栏追加查询参数 `instant_crash`，模拟不同阶段的失败并验证诊断界面：

| 参数值 | 模拟场景 |
|--------|----------|
| `boot`（或 `1`、留空） | 启动守护激活后立即进入诊断界面 |
| `reject` | 未处理的 Promise 拒绝 |
| `font` | 字体初始化完成后的启动失败 |
| `react` | 组件树渲染阶段的未捕获异常 |

示例：在开发服务器地址后追加 `?instant_crash=react` 即可触发对应场景。
