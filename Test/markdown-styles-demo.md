# Markdown 样式演示

这是一份用于「预览」应用的 **Markdown** 样例文档，覆盖常见排版元素，方便检查拟物纸面渲染效果。

> 提示：可从「文件」或「预览」中打开本文件。下文刻意堆叠多种语法，并非真实文章结构。

## 6. 表格

| 元素 | 预期观感 | 状态 |
| --- | --- | --- |
| 标题 | 衬线、居中或下划线 | 检查中 |
| 引用 | 墨线 / 浅底 | 检查中 |
| 代码 | 贴纸条、细边框 | 检查中 |
| 表格 | 纸上格线、表头略深 | 检查中 |

对齐示例（GFM）：

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| left | center | right |
| 甲 | 乙 | 丙 |

表格内也可有 `code` 与 **粗体**。
