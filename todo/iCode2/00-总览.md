## 马上要做的

- **第八期（`08-VFS-写时并发检查.md`，存储层）** 写文件时可带「期望内容版本」；不等则拒。不替调用方填写。不接入任何 agent。

- **第十一期（`11-运行时宿主syscall-hook.md`，运行时层）** Instant Node 实例创建时挂拦截链。文件 / 网络 / 终端壳层出沙箱都走这条链。按实例挂。不实现版本比对。与第八期可并行。

- **第九期（`09-iCode-agent-接入VFS并发检查.md`，策略）** 在 iCode agent 用的实例上挂拦截器：读成功则记下版本，写时交给第八期原语。用户自己的终端不挂。依赖第八 + 第十一期。

- **第十期（`10-github-desktop-接入VFS并发检查.md`）** 拆掉 github-desktop 用版本号优化 fileIndex 的旁路。不在本期给工作区写入接期望版本。只依赖第八期。

- **第十二期（`12-iCode复用vscodeAI面板.md`）** iCode「对话」tab 换成 vscode AI 面板。引擎仍用第三期已接好的那套。与第八至十一期正交。

第八、第十一、第十二期可并行。第九期在第八 + 第十一之后。第十期在第八之后。

## 两层分别干什么（第八 / 九 / 十一）

| 层 | 干什么 | 谁受益 |
|---|---|---|
| 存储（第八期） | 写时可以核对应版本 | 任何直接写 VFS 的人 |
| 运行时拦截链（第十一期） | 沙箱出门时能被策略拦住或改参 | 挂了拦截器的 Instant Node 实例 |
| agent 拦截器（第九期） | 记住上次读到的版本，写时带上 | 仅 agent 会话实例 |
